Diagnóstico de acesso GitHub

O StudioFrame usa automaticamente a credencial GitHub embarcada para o repositório GanaLD/mensagem-studio-portfolio. Não há login obrigatório. Este painel só aparece se a credencial não autenticar ou não tiver permissão de gravação; token manual é uma alternativa de recuperação.

  2. 2. Repositório
  3. 3. Gravação
  4. 4. Read-back
Recuperação: substituir token manualmente

Obrigatório para publicar: Contents = Read and write. Somente para o StudioFrame configurar o Pages automaticamente: Pages + Administration = Read and write. Actions/Workflows não são necessários.

A V6 testa primeiro a credencial embarcada. Se houver 403, o diagnóstico exibirá a camada e, quando fornecido pelo GitHub, a permissão exigida. Use o campo manual apenas para substituir uma credencial inválida ou sem acesso ao repositório.

O token nunca entra no HTML público, portfolio.json ou data/editorial-state.json.
